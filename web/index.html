Quickstart

Three clean steps to integrate into your terminal workflow.

01. INSTALL

Install Cmdora

Available on PyPI with clean Windows PowerShell integration.

pip install cmdora
02. ONBOARD

Configure API Key

Saves to system AppData without writing secrets to your repository.

cmdora config set-key
03. EXECUTE

Run Any Task

Cmdora translates your intent, verifies safety policy, and executes.

cmdora "Do the task"
