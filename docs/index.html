Get Started in 30 Seconds

Zero manual configuration files in your repository. Set up once globally and run from anywhere.

1

Install Package

Install Cmdora directly from PyPI via pip or uv.

pip install cmdora
2

Configure Gemini API Key

Securely save your key to user AppData without touching repo files.

cmdora config set-key
3

Run Natural Language Tasks

Give instructions in plain English. Cmdora plans and executes safely.

cmdora "list all python files"

Engineered for Safety and Speed

Designed specifically for Windows developers working with PowerShell and Git workflows.

⚡

Sub-second Deterministic Engine

Common file searches, project status checks, and Git queries run in <0.2s locally without waiting for LLM roundtrips.

🛡️

Destructive Command Blocker

Strict policy rules block irreversible actions such as rm -rf, Format-Volume, system directory mutations, and recursive file deletions.

🔍

Inspect Before Running

Use --dry-run on any command to preview the exact PowerShell script and its anticipated effect before making any modifications.

🤖

Gemini 3.1 Flash-Lite Core

Powered by the ultra-fast and lightweight Gemini 3.1 Flash-Lite model for concise, accurate command planning with low latency.

🔐

Workspace Containment

Path safety boundary ensures commands cannot traverse into system directories or tamper with parent files outside the current project.

📋

Full Audit Trail

Every planned task, user approval, and executed PowerShell output is recorded in a tamper-resistant local audit log for accountability.

--dry-run Safety Guarantee

Verify any proposed action with zero side-effects

Worried about an AI modifying your working tree? Add --dry-run to inspect the full plan, anticipated effects, and safety tier before committing to execution.
